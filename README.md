# 🧮 Python Tkinter Calculator – Simple GUI Arithmetic App

This project is a **basic desktop calculator** built with **Python** and **Tkinter**, providing a clean and intuitive interface for standard arithmetic operations.

## 💡 Features

- ➕ Basic operations: `+`, `-`, `*`, `/`
- 🔢 Number and decimal entry
- 🟰 Compute result with `=`
- 🧹 Clear screen with `C`
- ⬅️ Delete last digit using `←`
- ⚠️ Error handling for invalid inputs (e.g. division by zero)
- 🪟 Responsive grid layout for GUI scaling

## 🚀 Getting Started

### ✅ Requirements

- Python 3.x (recommended: 3.6+)
- Tkinter (included with standard Python distributions)

### ▶️ Running the App

1. Clone or download this repository:

   ```bash
   git clone https://github.com/matifelitti/Python-Calculator.git
   cd Python-Calculator
   ```

2. Run the calculator script:

   ```bash
   python Calculator.py
   ```

## 📌 Usage Instructions

Once the app is running:

- Click the number and operator buttons to enter expressions.
- Use `=` to compute the result.
- Use `C` to clear the screen.
- Use `←` to delete the last entered character.
